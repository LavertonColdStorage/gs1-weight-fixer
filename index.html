GS1 Weight Fixer

Fill in zero carton weights from the GS1 barcode

How it works

  1. Save the spreadsheet from the email (.xlsx, .xls or .csv) and drop it below. You can drop several at once.
  2. Every row whose weight is 0 gets the net weight read from that carton's GS1 barcode (AI 310n, net kg; e.g. 3102 001570 = 15.70 kg).
  3. Check the list of changes, then download the fixed file. Nothing else in the file is changed.

Files never leave your computer. Everything happens in this browser tab.
